# VLA 与 sim2real——当大模型长出手

> VLA（Vision-Language-Action Model）是具身智能当前的"大模型时刻"：把预训练视觉语言模型（VLM）的常识，接上一个输出机器人动作的头，让"把桌上的杯子收进水池"变成一句可以直接执行的指令。这一章综述这条路线的代表作，然后算 sim2real 的完整账单——最后回答一个问题：它和本系列的确定性栈，到底谁包含谁。

---

## 1. VLA 的基本配方

**VLA = 预训练 VLM + 动作头**。VLM（如 PaliGemma、Llama 类）提供视觉理解 + 语言理解 + 世界常识；动作头把模型的输出空间从"词元"扩展到"机器人动作"。训练分两段：先在海量**跨具身**数据（Open X-Embodiment 一类）上预训练，再在目标机器人/任务上微调。

代表型号的三代速记：

- **RT-2**（Google DeepMind，2023）：证明"动作即词元"——把机器人动作离散成特殊 token，让 VLM 直接"说出"动作。55B 参数，语义泛化惊艳（"把恐龙玩具拿给泰勒斯威夫特"也能执行），但推理频率低（1–3Hz），精细操作吃力；
- **OpenVLA**（2024）：开源路线的旗舰——7B 参数，Llama 2 / Prismatic 骨干，**970k 条 Open X-Embodiment episode** 预训练，消费级 GPU 可微调。它的意义是让 VLA 从实验室特权变成社区基础设施；
- **π0**（Physical Intelligence，2024）：VLM（PaliGemma）+ 独立**动作专家**，用 **flow matching** 生成连续动作块——高频、平滑、灵巧。训练数据横跨 **7 种机器人形态、68 个任务**，现已进入 Hugging Face **LeRobot** 生态。"VLM 管理解、专门的动作模型管生成"这个分工，基本定调了后续架构。

## 2. LeRobot：学习派的"ROS"

Hugging Face 的 **LeRobot** 之于学习派， roughly 相当于 ROS 之于确定性派：数据集格式（LeRobot Dataset）、策略库（ACT、Diffusion Policy、π0 的开源实现）、采集硬件方案（低成本遥操作臂）、仿真集成。**两个生态的对称性值得驻足**：ROS 的 package ≈ LeRobot 的 dataset/policy；URDF ≈ 数据 schema；MoveIt ≈ 策略库。本系列前十一章的每一层，在学习派世界里几乎都有对位物——除了安全（14.3）。

## 3. VLA 不是栈的替代品，是栈的"策略层候选人"

一个常被误解的点：VLA 不会取代 ros2_control/MoveIt/安全层。真实的部署形态是**分层混合**：

```
语言指令 → VLA（或 LLM+VLA）→ 语义理解与技能选择
    → Skill / Runtime API   ← 本项目留好的插槽（12 篇接口图）
    → MoveIt / ros2_control  ← 动作仍然由确定性栈执行
    → SafetySupervisor       ← 无论如何，最终停止权不变
```

VLA 输出的是"接下来做什么"（目标位姿/技能调用/动作块），而"怎么安全地做"仍是确定性栈的地盘。**频率匹配**是当前的真实矛盾：VLA 十几 Hz，控制几百 Hz，中间要靠动作块插值和低层追踪来弥合——这正是 π0 用 flow matching 输出动作块的原因。

## 4. sim2real：从仿真学到的能不能用到真机

**Reality gap**（现实差距）的三个来源与三件武器：

| 差距来源 | 内容 | 武器 |
|---|---|---|
| 视觉外观 | 渲染不像真实（材质、光照） | **域随机化**（随机光照/纹理/位置，让模型学到不变特征）；照片级渲染器；真机数据混训 |
| 物理差异 | 接触、摩擦、时滞不同 | 系统辨识、物理参数随机化、真机微调 |
| 系统差异 | 延迟、噪声、标定误差 | 延迟建模、动作块（对延迟鲁棒）、在线适配 |

判断当前水位：仿真训练 → 真机零样本在简单抓取上已可用，精细/接触丰富的任务仍需真机数据。**这也是 12 篇 A1（纯仿真）成为项目头号边界的原因**——本项目连 gap 的测量都还没开始（M6 Sim2Real 只有一张验收模板）。

## 5. 项目实例：插槽已备，大脑未至

把 12 篇的接口图放进本章语境，项目的"VLA 就绪度"评估：

- **已就绪**：Runtime API（能力接口、非自然语言——动作层的标准 VLA 对接面）；Skill Manifest（LLM 选技能的词表，cost 三元组即 SayCan 式打分的输入）；安全壳（VLA 输出再离谱，也要过 SafetyCheck）；Episode/数据管线（微调数据从哪来）；
- **未就绪**：真机（A1）、力控（A3）、泛化感知（A4）、以及任何学习组件（A5）。

一句话总结这个项目的位置：**它把 VLA 落地需要的"下半身"造完了，"上半身"（模型、数据、真机）一片空白**——而下半身的每一层（安全独立、能力声明、技能词表、可重放数据）恰恰是 VLA 论文里经常被一笔带过的工程前提。

## 6. 边界与不足（对本章的"综述"自我声明）

VLA 领域月度级演进，本章数字（970k episode、7 形态 68 任务）为 **2024–2025 年快照**——第三代竞赛（Gemini Robotics 2 / On-Device、StarVLA、Helix）与 2026 产业全景见 **16–17 篇**；"VLA + 确定性栈"的分层混合是当前主流工程判断而非定论，端到端派与分层派之争仍在进行（18 篇的流派 C 有最新变量）；仿真到真机的零样本泛化数字高度依赖任务域，不存在通用结论。

## 7. 一句话总结

> VLA 给机器人接上了"常识"，LeRobot 给学习派造了"ROS"，sim2real 是两条路线共同的天花板——而所有这些上层建筑，都踩在确定性栈打好的地基上：安全的最终停止权、可验证的技能接口、如实声明的能力边界。
