# 世界模型——机器人怎么记住过去、相信现在、预测未来

> 规划器问的第一句话永远是"世界现在什么样"。谁来回答？世界模型（World Model）——机器人的认知真相源：它缓存实体的状态、维护实体间的关系、保存历史的轨迹、外推未来的位置。这一章讲世界模型的分层设计，以及从"确定性快照"到"概率信念"的关键一跳。

---

## 1. 为什么需要世界模型

没有世界模型的机器人系统是这样的：感知节点有一份物体列表、规划器有自己的缓存、任务层记着自己的目标状态——**三份数据三张嘴，一旦不一致，系统就精神分裂**（规划器以为盒子还在桌上，感知早就看见它被拿走了）。

世界模型的第一性职责就是**单一真相源**：所有"世界现在什么样"的询问只有一个答案提供者。AGENTS.md 架构规则第 3 条原文：**WorldModel 是世界认知真相源，所有层读取环境状态必须从 WorldModel 获取**——并配有一条边界规则：500Hz 的关节状态不进 WorldModel（那是 ros2_control 的实时真相源，05 篇）。**认知真相（世界什么样）与实时真相（身体此刻的关节角）分离**，是这个设计最值得记住的判断。

## 2. 世界模型的五层解剖

一个够用的机器人世界模型至少五层（自下而上）：

| 层 | 职责 | 典型内容 |
|---|---|---|
| **Entity** | 有什么东西 | Robot / Object / Obstacle / Zone 的存在性登记 |
| **State** | 它现在什么样 | 位姿、grasp_state、attached_to |
| **Relation** | 它们之间什么关系 | on / near / inside / attached / above / below |
| **History** | 它曾经什么样 | 状态时间序列 |
| **Prediction** | 它即将什么样 | 运动外推、碰撞预测 |

**Relation 层最容易被低估**。技能的前置/后置条件（"抓取前物体必须在桌上且未被抓着"）全是关系查询——没有关系层，技能的 precondition 就退化成"查个坐标在不在范围内"（11 篇）。

## 3. 关键一跳：从确定性到概率

经典世界模型存的是**确定性快照**："盒子在 (0.3, 0.1, 0.5)"。但感知是有噪声的、多源的、有时滞的——GT 说是这里，视觉说在那里，差了 0.3 米，信谁？确定性表示无处安放这个冲突，只能加个 `uncertain` 标志位——**用布尔量掩盖概率问题**。

成熟的做法是把状态表示成**信念（belief）**：高斯分布（均值 + 协方差）+ 置信度 + 来源。多源融合按噪声模型加权，预测按过程噪声随时间膨胀。这就是状态估计（卡尔曼滤波一族）进入"世界模型"这个时髦名词的方式——**在深度学习的世界模型（Dreamer 一类）流行之前，概率估计一直是世界模型的地基**。

## 4. 项目实例：五层 → 六层的一次诚实升级

项目的 WorldModel（`multi_arm_world_model`）起初按五层建：`state_database.py`、`object_tracker.py`、`relation_layer.py`、`history_layer.py`、`prediction_layer.py`，由 `world_model_node.py` 统一对外服务，BT 里有专门的 `AsyncQueryWorldNode` 查询世界（06 篇）。

M7.6 把它升级为**六层**，新增 `belief_layer.py`：

- **GaussianBelief**：3D 位置 + 对角协方差 + 置信度 + 来源；`uncertainty = 协方差迹/3`；`predict(velocity, dt)` 前向预测——均值加位移、方差加过程噪声；
- **BeliefUpdater 多源融合**：GT 源 `gt_variance=0.001`（近乎全信），视觉源 `variance = base × (1−confidence) + gt_variance`（置信度越低越不信）——07 篇那个 0.3m 的 `contradiction_threshold_m` 冲突阈值在这里有了概率语义；
- 验收记录里写得很直白：M7.5 及之前是"确定性位置 + 标志位（uncertain/contradiction）"，M7.6 升级为概率 belief，**同时修复了 6 个架构缺陷**。

**演进注记**：五层世界模型（M6.1）曾被作为架构成果宣布，八个月后它自己长出了第六层、并承认前五层有六个缺陷。这不是打脸——**"确定性快照 + 标志位"是合理的 v1**（先把闭环跑通），概率化是闭环成立之后的第二阶段。世界模型的演进顺序（Entity/State → Relation → History/Prediction → Belief）本身就是一条可复用的建设路线。

## 5. 边界与不足

实体类型是预定义的（Robot/Object/Obstacle/Zone），没有开放词汇的物体识别；关系是手工规则推理（on = 支撑几何判定），没有学习的语义关系；预测是线性外推（velocity × dt），对"人走进来"这类非线性事件无能为力（M5.6 Level 2 动态障碍是靠感知刷新而不是预测解决的）；学习型世界模型（表征学习/Dreamer 类）完全缺席——那是学习派的地盘（13/14 篇）。

## 6. 一句话总结

> 世界模型 = 单一真相源 + 五层结构 + 概率信念。它的成熟标志不是"存了多少状态"，而是能诚实地说"我相信盒子在 (0.3, 0.1, 0.5)，标准差 2 厘米，依据是 0.6 置信度的视觉"。
