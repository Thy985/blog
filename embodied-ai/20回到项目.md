# 回到项目——业界坐标下的定位图与路线修正

> 业界篇的最后一篇收拢五份调研：先画一张"业界标配 vs 项目现状"的定位图，再做一份约束下的路线修正——哪些下一步值得走、哪些刻意不走，以及如果三个流派里某一个赢了，这张图哪些部分会变。

---

## 1. 定位图：业界标配 vs 项目现状

| 业界标配（2026） | 项目现状 | 差距性质 |
|---|---|---|
| 真机部署（宇树 5500 台、Figure 试点、1X 家庭） | 纯仿真（Gazebo/WSL2） | **路线性**（12 篇 A1） |
| 学习组件（VLA 第三代、ACT/Diffusion） | 零学习组件 | **路线性**（A5），但接入通道已现成（19 篇） |
| 数据飞轮（遥操作/合成/共享三层合流） | 半个飞轮（Episode + 导出器，无人消费） | **工程性**——差一个格式转换器和第一个消费者 |
| 生成式场景（Cosmos 3、Genie Sim 3.0、HY-World 2.0） | 手写域随机化 | **工程性**——M6.S 的升级路径清晰 |
| 基础模型评测（Isaac Lab-Arena/RoboArena） | 自家验收报告（15 场景 + 7 不变量） | **工程性**——把任务集映射到标准基准即可 |
| 力控与触觉（Franka 类平台、灵巧操作研究入场费） | 负声明 `force_control: false` | **路线性**（A3），仿真内无解 |
| 遥操作采集（1X 工厂、VR 遥操） | 无 | **工程性**——仿真内可自造（脚本专家策略当"教师"） |
| 分层混合架构（VLA 上层 + 确定性栈下层） | **已达成**（确定性栈完整 + 插槽就位） | ✅ 唯一已达标项 |

**定位结论**：这台纸面人形在 2026 年的产业坐标系里，位置是"**确定性栈完整样本 + 数据飞轮前半圈**"。它的独特价值不在任何一个单点技术（每一项业界都有更好的），而在**作为"学习派入场前的世界"的完整记录**——这正是业界文档不会给你画的那张图。

## 2. 路线修正：约束下的下一步

原则沿用 00 篇约定（技术路线不预设正确；单卡、仿真、无真机、无预算的约束不变）。按"性价比 × 确定性"排序：

**第一梯队（确定性高、成本低、飞轮闭环）**

1. **消费自家数据**：`dataset_exporter` 加 LeRobot 格式后端 → 用 LeRobot 的 ACT/Diffusion Policy 在自家 Episode 上训第一个策略（哪怕只学会"抓方块"）。这一步把"半个飞轮"变成"一个飞轮"，也是 A5（零学习组件）的破局点；
2. **接标准评测**：任务集映射到 LIBERO/SimplerEnv 结构——从此这个项目的任何策略有**行业可比的分数**，告别"自家验收报告自说自话"；
3. **LLM 选技能**：用任意可微调 LLM + Skill Manifest 的 cost 三元组做 SayCan 式技能选择——这是 17 篇"模型无关插槽"的最小通电实验，不需要 VLA。

**第二梯队（价值高、工程量大）**

4. **生成式场景升级**：M6.S 场景生成器 → HY-World 2.0 / Genie Sim 3.0 式照片级场景（Gazebo 物理内核保留，外壳升级）——数据多样性质变；
5. **脚本专家策略**：给每个技能写一个确定性"教师"，批量生成成功轨迹（仿遥操作，无需真人）——数据量级从"百"到"万"；
6. **WorldModel 接学习**：belief 层给学习策略当先验/验证器（A 流派服务 C 派的具体形态）。

**刻意不做（负清单）**

- 不从零训 VLA（数据量级差三个数量级，17 篇）；
- 不追真机（约束所限，且 12 篇已论证 gap 不可绕）；
- 不把 GPT-6 Astra 的 ICL 具身结果当前提——**待复现的单篇论文不入路线图**（18 篇证据强度约定）。

## 3. 情景分析：三个流派若分出胜负

| 若胜出的是… | 项目图的变化 | 插槽命运 |
|---|---|---|
| **B 流派**（生成式数据引擎成为主流） | M6.S 升级从可选变必选；场景生成成本趋零 | 不变——执行栈照旧 |
| **C 流派**（ICL/隐式世界模型被复现） | 训练管线可部分绕过，第一梯队第 3 步直接跳到"通用大脑 + Runtime API" | **更值钱**——换大脑不换接口，恰恰是"非自然语言"设计的兑现 |
| **A 流派**（分层混合继续是工程默认） | 路线图不变 | 原样 |

注意第三行：**项目当前押的其实就是"没有流派完全胜出"的混合世界**——分层混合是 2026 年的行业默认架构（17 篇共识 3），路线图在这个情景下已就位。

## 4. 系列的最终结论

二十一章走完，留下三句话：

1. **对个人**：具身智能的入场券不是"训一个 VLA"，而是"把确定性栈和数据管线做扎实，插槽留给大脑"——本项目 M1–M7 + 19 篇接入路径就是这条路的完整示范；
2. **对行业**：2026 年的产业共识（分层混合、数据飞轮、评测瓶颈）全部指向同一个结构——**学习派越强大，确定性栈的基建价值越高**；安全、互斥、能力声明、可重放数据，这些"不性感"的部分是所有路线共同的承重墙；
3. **对方法**：三个系列（天气、prime-rl、具身）共同的最后一句还是那句——**能力的诚实**。`force_control: available: false` 这行 YAML、`待复现`这三个字、`刻意不做`这个清单，和 10/10 的验收通过率一样，都是产出。

## 5. 一句话总结

> 定位图上只有一项达标（分层混合的执行栈），但那一项恰好是 2026 年所有路线共同踩着的地基——把数据接上飞轮，把插槽通上电，其余的交给时间。

系列到此完结。业界数据快照：2026-10-24。
