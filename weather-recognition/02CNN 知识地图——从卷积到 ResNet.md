## 2.卷积：CNN的起点

### 2.1什么是卷积

卷积是CNN的基本操作。用一个小的**卷积核**在图像上滑动，每个位置做**逐元素乘法再求和**，最后输出特征图。

**可以这样理解**：

拿着3x3的放大镜在照片中滑动。每滑倒一个位置，你就看到这个3x3区域，把它压成一个数字。滑动整张图，就得到一张新的“特征图”。



### 2.2关键概念

| 概念           | 含义               | 通俗理解             |
| -------------- | ------------------ | -------------------- |
| 卷积核大小     | 每次看多大的区域   | 放大镜的尺寸         |
| 步长(stride)   | 每次滑动多少格     | 放大镜每次移动的距离 |
| 填充（padding) | 边缘补多少圈       |                      |
| 通道(channel)  | 输入/输出的深度    |                      |
| 权值共享       | 同一个卷积核扫全图 |                      |

### 2.3为啥卷积适合图像

- **局部连接**：图像的特征是局部的，边缘、纹理、形状都只和邻近像素有关。
- **权值共享**：同一个特质可能出现在图像任何位置，不需要为每个位置单独学参数。
- **平移不变性**：物体移动一点，卷积仍然能识别。

### 2.4对应项目决策

天气分类项目里，卷积层负责提取：

- 低层：边缘、颜色、纹理
- 中层：云块形状、雨滴纹理、雪地反光
- 高层：整体天气语义

并且在小样本下，卷积层的参数主要来自ImageNet预训练，而不需要从头学。

## 3.池化：降维与不变性

### 3.1什么是池化

池化是下采样操作。最常用的是**最大池化**：在一个小窗口里取最大值。

**可以理解成**：

把一张大图缩小。每个2x2区域只保留最大的那个数。这样图变小了，但重要的特征被保留了。

### 3.2为啥需要池化，又为啥是在卷积后池化

我的理解是：可以通过缩小特征图的空间尺寸，

一方面减少计算量，

另一方面去重冗余细节，让模型注重更重要的特征，从而提高其泛化能力。

**那为啥在卷积之后进行池化**：卷积的核心作用是提取不同层级的有用特征，然后池化才有东西可以压缩，并删除一下卷积后冗余特征信息。并且扩大了感受野，整合了上下文信息。

### 3.3对应项目决策

天气分类项目里，池化层帮助网络从局部纹理逐步过渡到全局天气判断。但池化也会丢失空间信息，所以现代架构(如ResNet)更倾向于用**步长卷积**替代部分池化。

## 4.感受野：CNN的“视野"

### 4.1什么是感受野

感受野是输出特征图上的一个像素，对应输入图像上的区域大小。

**通俗理解**：

第一层卷积看到的是3x3的小块；第二层看到的是更大的块；越往后，看到的范围越大。这个范围就是感受野。

### 4.2为啥感受野重要

- 感受野大小：网络只能看到局部，无法理解整体天气
- 感受野太大：可能引入过多无关信息。
- 天气分类需要足够大的感受野来判断”整张图是晴天还是多云".

### 4.3对应项目决策

ResNet通过残差连接和深层堆叠，能够获得很大的感受野。这是它适合图像分类的一个原因。

## 5.激活函数

### 5.1为什么需要激活函数

卷积是线性操作。如果没有激活函数，多层卷积叠加还是线性的，网络再深也等价于一层。激活函数引入非线性，让网络能拟合复杂函数。

### 5.2 常用激活函数

| 激活函数 | 公式              | 特点                    | 通俗理解           |
| :------- | :---------------- | :---------------------- | :----------------- |
| Sigmoid  | 1/(1+e⁻ˣ)         | 输出 0~1，易梯度消失    | 老式，现在少用     |
| Tanh     | (eˣ-e⁻ˣ)/(eˣ+e⁻ˣ) | 输出 -1~1，仍会梯度消失 | 比 Sigmoid 好一点  |
| ReLU     | max(0, x)         | 简单、快、缓解梯度消失  | 负数变 0，正数不变 |
| GELU     | x·Φ(x)            | 平滑版 ReLU             | Transformer 常用   |

### 5.3对应项目决策

ResNet默认使用ReLU.项目没有换激活函数，因为ReLU在这个规模下足够稳定。

## 6.归一化：BN和它的朋友们

### 6.1批归一化(BN)

BN 对每个 mini-batch 的激活值做标准化：减均值、除标准差，再乘一个可学习缩放、加一个可学习偏移。

**通俗理解**：假设一个班有30个学生，这次数学考试全班平均分只有50分，老师就把所有人的分数整体往上拉，让全班平均分变成70分，同时把分数的松紧度调整到合理范围。它的操作逻辑是：‌**盯着同一门课，统计全班同学的成绩分布，统一调整所有人的分数**‌

### 6.2层归一化(LN)

点了一杯奶茶，发现糖放多了太甜，珍珠放少了没嚼劲，你自己单独调整糖量和珍珠量，让这杯奶茶的甜、香、Q弹的整体口感变得均衡。

它的操作逻辑是：‌**完全不管别人，只盯着自己这一杯奶茶的所有配料，调整整体的口味分布**

### 6.3BN的作用

- **加速训练**：允许更大学习率
- **缓解梯度消失/爆炸**:稳定每层输入分布。
- **轻微正则化**：batch统计量带来噪声

### 6.4BN的变体

| 方法 | 归一化维度   | 适用场景         |
| :--- | :----------- | :--------------- |
| BN   | batch 维度   | 大 batch，CNN    |
| LN   | 特征维度     | RNN、Transformer |
| GN   | 通道分组     | 小 batch         |
| IN   | 单样本单通道 | 风格迁移         |

### 6.5对应项目决策

天气分类项目数据量小，batch size受限。BN在小batch下统计量不稳定，这是潜在风险

## 7.正则化：防止过拟合

### 7.1为什么小样本容易过拟合

约4990张图，对深层CNN来说偏少。模型容量大、数据少，就会记住训练集而不是学习规律

### 7.2常用正则化方法

| 方法         | 原理                     | 通俗理解                 |
| ------------ | ------------------------ | ------------------------ |
| Dropout      | 训练时随机丢弃部分神经元 |                          |
| Weight Decay | 限制权重大小             | 不让任何一个特征权重过大 |
| 数据增强     | 扩充训练样本             |                          |
| 早停         | 验证指标不在提升就停     |                          |
| BN           | 轻微正则化               |                          |

### 7.3对应项目决策

项目使用了：

- Dropout
- Weight Decay
- 数据增强
- 早停

这些正则化手段是标准配置，但具体效果还需要实验验证。

## 8.残差连接与ResNet

### 8.1深层网络问题

理论上，网络越深，表达能力越强。但实际上：

- **梯度消失**：反向传播时梯度越来越小，浅层约不到东西。
- **退化问题**：网络加深后，训练误差反而变大，不是过拟合，而是优化困难。

### 8.2残差连接

残差连接的核心思想是：让神经网络学习**残差** F(x)=H(x)-x,而不是直接学H(x).输出=F(x)+x

### 8.3 ResNet架构

ResNet的核心是堆叠残差块。

常见版本：

| 版本      | 层数 | 特点             |
| :-------- | :--- | :--------------- |
| ResNet18  | 18   | 轻量，适合小数据 |
| ResNet34  | 34   | 中等             |
| ResNet50  | 50   | 瓶颈块，参数量大 |
| ResNet101 | 101  | 更深             |

## 8.4对应项目抉择

项目里用了 ResNet18 和 ResNet50 作为集成伙伴。需要注意的是：在标准 ImageNet 基准上，ResNet50 通常强于 ResNet18；但在**本项目的本地验证集**上，单模型指标反了过来——ResNet18 的 Local F1 为 **0.923**，ResNet50 为 **0.891**。然而集成结果同样反直觉：**本地更强的 ResNet18 导致集成崩溃（−0.012），本地更弱的 ResNet50 反而帮助了集成（+0.006）**。仓库的集成互补性分析显示，伙伴价值排序与单模型精度排序相反、与预测分歧率排序一致——这正是第 6 篇要展开的核心：**集成价值来自系统差异，而非伙伴强度**

## 9.迁移学习：小样本的默认选择

### 9.1什么是迁移学习

先在大型数据集上预训练，再把学到的特征迁移到新任务。

### 9.2迁移学习策略

| 策略       | 做法                       | 适用场景 |
| ---------- | -------------------------- | -------- |
| 冻结全部   | 只训练分类头               | 数据极少 |
| 冻结部分   | 冻结浅层，微调深层         | 数据较少 |
| 全部微调   | 所有层都训练               | 数据充足 |
| 差分学习率 | 浅层小学习率，深层大学习率 | 常用     |

### 9.3对应项目决策

项目默认使用ImageNet预训练ResNet.这是小样本下的标准选择

## 10.完整知识点

```
输入图像
    │
    ▼
[卷积层] ← 提取局部特征
    │
    ▼
[激活函数 ReLU] ← 引入非线性
    │
    ▼
[池化/步长卷积] ← 降维、扩大感受野
    │
    ▼
[归一化 BN] ← 稳定分布、加速训练
    │
    ▼
[残差块] ← 解决深层退化
    │
    ▼
... 重复堆叠 ...
    │
    ▼
[全局平均池化] ← 压缩空间信息
    │
    ▼
[全连接层] ← 分类
    │
    ▼
[Softmax] ← 输出概率
    │
    ▼
预测类别
```

## 12. 解释与推断

**FACT（事实）**

- ResNet 使用残差连接。
- BN 对激活值做标准化。
- Dropout 训练时随机丢弃神经元。
- 迁移学习使用预训练权重。

**OBSERVED（观察）**

- ResNet18 导致集成崩溃，ResNet50 帮助集成。
- CLIP 因部署约束被否决。

**INFERENCE（推断）**

- 模型强度与集成贡献不是正相关。
- 小样本下迁移学习是必要选择。
- BN 在小 batch 下可能不稳定。

**HYPOTHESIS（假设）**

- 如果数据量更大，从零训练可能可行。
- 如果换用 GN，小 batch 下可能更稳定。
- 如果冻结 BN 统计量，迁移效果可能更好。

------

## 13. 负结果与教训

这一篇的负结果：

1. **更强的模型不一定更好**：ResNet18 比 ResNet50 强，但集成贡献相反。
2. **CLIP 被否决**：不是效果问题，是部署问题。
3. **教科书知识需要验证**：BN、Dropout、Weight Decay 是标准配置，但具体效果依赖数据分布。

教训：

- 不要盲目堆模型。
- 部署约束前置。
- 每个知识点都要对应实验验证。

---

## 14.可迁移结论

- CNN的核心是卷积+池化+激活+归一化+残差
- 小样本优先迁移学习。
- ResNet 是图像分类的强基线。
- BN、Dropout、Weight Decay 是标准正则化。
- 模型强度不等于集成贡献。
- 部署约束决定模型选型。
