# 数据与增强——为什么增强必须匹配目标分布

> 系类第3篇：当教科书技巧失效，问题往往不在技巧本身。

### TL:DR

天气分类项目最重要的增强发现这又一个：**关闭合成噪声是最大的单项提升**。但这不是一个“噪声不好”的简单结论——噪声效应是**非单调的**，关键在于合成噪声偏离了真实天气图像的分布，模型学到的是噪声本身的模式，而不是天气特征。同样，Mixup,CutMix,加权采样，类别权重，推理锐化在这个分布上均为负向或异常。这一篇把数据增强讲透：传统增强的适用边界在哪里，为什么“补分布”比“造数据”更接近增强的本质，以及如何判断一个增强策略是否匹配你的目标分布。

## 1.问题背景：增强的朴素直觉

第 1 篇讲了约束：约 4,990 张训练图，1.75:1 类别不平衡，隐藏测试集存在分布偏移。第 2 篇讲了模型：ResNet + ImageNet 预训练是默认起点。

数据量小，直觉上应该“多做增强”。翻转、裁剪、颜色抖动是标配；Mixup、CutMix是“更强”的正则化；加噪声可以提升鲁棒性；类别不平衡可以用加权采样或类别权重来补。

这个直觉在ImageNet级别的数据是合理的。但在小样本+分布偏移+类别不平衡的三重约束下，它开始出现问题。

项目里的实验揭示的不是“某个技巧不好用”，而是一个更根本的问题：**增强是在数据分布做干预，而不是在”造更多数据“。** 如果干预的方向偏离了目标，增强越多，偏离越远。

---

## 2.知识地图：数据增强到底在做什么

### 2.1传统增强：在保持语法的前提下扰动 

翻转、随机裁剪、颜色抖动、旋转、Cutout,这些方法的共同点是：**不改变图像的语义标签。**一张sunny图水平翻转后仍然是sunny,裁剪掉边缘后仍然是sunny,颜色轻微变化仍然是sunny.

它们的作用是让模型看到同一语义的不同外观变体，从而**对不相关的变异不变**.

### 2.2Mixup与CutMix:在样本之间做插值

Mixup把两张图按比例混合，标签也按同样比例混合。CutMix从一张图裁剪到另一张图上，标签按面积比例混合

它们的设计假设是：**特征空间中的线性插值是”有意义“的**。如果输入时70%的A和30%的B，模型应该输出70/30的软标签。这在类别边界平滑、样本充足的场景下成立。

但在小样本下，这个假设可能不成立。一项针对于数据稀缺场景的研究发现，CutMix和Mixup在标签混合概率增加时性能**显著下降**，CutMix从25.5%降到23.8%,Mixup在更高混合概率下降到7.7%,研究者的解释是：**保持样本简单的增强策略在数据稀缺时更有效，而引入标签混合和跨样本交互的复杂正则化可能有害**

### 2.3合成噪声：一种特殊的增强

加噪声和翻转、裁剪不同。翻转和裁剪是在**语义空间**中做等变变换，如一只猫无论怎么裁剪和翻转都是这只猫；噪声是在**像素空间** 中引入干扰，可能产生真实数据中不存在的模式。

有研究表示，合成样本可能包含真实数据中不存在的**伪影** ，例如结构化噪声、内容错误或不现实的风格；合成过程还可能因为对数据流形的不均匀采样而引入偏差。这些伪影落在真实分布的支持集之外，模型如果把它们当作特征来学，学到的就是**噪声的模式** ，而不是**天气的模式**

### 2.4类别不平衡处理：加权采样与类别权重

加权采样让少数类被采到概率更高；类别权重让少数类的损失贡献更大。它们的目标是让模型不偏向多数类。

但这两种方法都在**改变训练时的有效分布**。如果平台测试集的分布与训练集不同（存在分布偏移），在训练集上”纠正“不平衡可能反而让模型对测试集的分布不适应。

## 3.项目里的增强实验：发生了什么

### 3.1合成噪声：最大单项提升，但效应非单调

关闭合成噪声带来了**平台+0.17** 的提升，时项目里最大的单项增强相关改进。

但这个结论不能简化成”噪声有害“。噪声的效应是**非单调的**——低强度噪声可能带来轻微正则化效果，高强度噪声开始引入伪影，模型逐渐学习到噪声模式而非天气特征。关键变量不是”加不加噪声“，而是**噪声的分布是否与真实天气图像中可能出现的噪声重合。**

### 3.2Mixup与CutMix:均为负向或者异常

项目里Mixup和CutMix没有带来正向收益。这和小样本+分布偏移的约束是一致的。

- **Mixup的致命缺陷**：它是全像素的加权融合，相当于给本就模糊的雨雾土再叠加另一张图的半透明虚影。
- CutMix的问题则是**局部信息被破坏和标签语义错配**。它的随机贴片可能直接遮蔽或替换对天气判别至关重要的局部区域

### 3.3分辨率与混合权重：本地升、平台降

项目里分辨率和混合权重两个维度都出现了“本地验证上升、平台指标下降”的反转。

这个现象和增强的分布匹配直接相关。提高分辨率在本地验证集上可能让模型看到更多细节，从而提升本地指标；但如果平台测试集的分布对分辨率的敏感性与本地不同，本地收益就不会迁移。混合权重的搜索同理——在本地验证集上找到的“最优权重”可能是在**过拟合验证集的分布**，而不是在逼近平台分布。

### 3.4加权采样与类别权重：没有接近问题

1.75:1 的不平衡用加权采样或类别权重来处理，直觉上合理。但项目里这些方法没有带来正向收益。

一个可能的解释是：不平衡本身不是主要矛盾，**分布偏移才是**。在训练集上强制纠正不平衡，可能让模型对训练集的类别先过度校验，而平台测试集的类别先验未必与训练集一致。在分布偏移存在时，”纠正不平衡”和“匹配目标分布”可能是两个方向的目标。

---

## 4.核心规律：增强是“补分布”，不是“造数据”

把上面这些现象串起来，可以得到一个统一的解释框架。

数据增强的本质不是”制造更多数据“，而是**在训练分布覆盖不足的区域补充样本**。翻转和裁剪补的是”同一语义在外观上的覆盖“；Mixup补的是”类别边界附近的覆盖“；合成噪声补的是”噪声条件下的覆盖“。每一种增强都在**扩展或移动训练分布的支持集**

问题在于：**你补充的方向，和目标分布方向一致吗？**

如果目标分布中 cloudy 和 sunny 的边界本来就是模糊的，那么在边界附近做 Mixup 插值可能是有益的——它让模型看到边界附近的软过渡。但如果目标分布中这个边界是清晰的（只是某些样本因为光照、角度而看起来模糊），那么 Mixup 产生的软标签就是**人为制造的模糊性**，模型学到的是“这两类可以混”，而不是“这两类在特定条件下容易混”。

合成噪声也是同理。如果真实天气图像中确实存在传感器噪声、压缩噪声、低光照噪声，那么加入类似分布的噪声是有益的。但如果合成噪声引入了真实数据中不存在的结构化伪影，模型就会把这些伪影当作判别信号。外部研究明确指出：**合成数据与真实数据分布之间的差距，可能使合成样本包含真实数据中不存在的伪影，从而在未补偿的情况下导致性能退化**

## 5. 结果与证据

| 增强策略         | 项目结果                        | 与分布匹配的关系                                        |
| :--------------- | :------------------------------ | :------------------------------------------------------ |
| **关闭合成噪声** | **平台 +0.017（最大单项提升）** | 合成噪声偏离真实天气图像分布，引入伪影                  |
| **Mixup**        | 负向或异常                      | 小样本下标签混合损害性能；类间边界不天然平滑            |
| **CutMix**       | 负向或异常                      | 同上；外部研究也发现天气场景下 CutMix 与 MixUp 行为分化 |
| **分辨率**       | 本地升、平台降                  | 本地最优分辨率 ≠ 平台最优分辨率                         |
| **混合权重**     | 本地升、平台降                  | 权重搜索过拟合本地验证集分布                            |
| **加权采样**     | 无正向收益                      | 不平衡不是主要矛盾，分布偏移才是                        |
| **类别权重**     | 无正向收益                      | 同上                                                    |

证据来源：`configs/N1..N5`、`scripts/noise/`、`experiments/negative_results/`、`knowledge/`、`analysis/platform_gap`。

## 6. 解释与推断

**FACT（事实）**

- 关闭合成噪声是项目最大的单项增强相关提升。
- Mixup、CutMix、加权采样、类别权重、推理锐化在项目实验中均未产生正向收益。
- 分辨率与混合权重出现本地升、平台降的反转。

**OBSERVED（观察）**

- 噪声效应非单调，存在一个从“可能有益”到“开始有害”的拐点。
- 外部研究在天气相关任务中也观察到 MixUp 持续有害、CutMix 行为分化的现象。

**INFERENCE（推断）**

- 增强的效果取决于它扩展训练分布的方向是否与目标分布对齐。
- 在小样本 + 分布偏移下，增强的“伪影风险”被放大。
- 在本地验证集上搜索增强超参数，有过拟合验证集分布的风险。

**HYPOTHESIS（假设）**

- 如果合成噪声的分布能更贴近真实天气图像的噪声分布，噪声可能不再有害。
- 如果先做域适应或分布对齐，再应用 Mixup/CutMix，结果可能不同。
- 在数据量更大的条件下，某些在项目里失效的增强可能重新有效。

## 7.负结果与教训

这一篇的负结果本身就是核心内容：**多个教科书增强技巧在这个分布上失效**

教训：

1.**增强不是“越多越好”，也不是“越强越好”。**

2.**小样本放大了伪影风险**。数据越少，模型越容易把合成伪影当成真实特征来拟合。

3.**标签混合不是没有代价**。Mixup/CutMix在样本充足、边界平滑时有效；在数据稀缺、边界模糊时，软标签可能引入有害的歧义。

4.**本地验证集上的增强收益不可以完全信任**。

5.**类别不平衡处理不能替代分布匹配**。如果分布偏移时主要矛盾，纠正训练集不平衡可能不是正确的方向。

---

## 8.可迁移结论

- **先问题“目标分布长什么样”，再选增强。**不要默认翻转、裁剪、Mixup是安全的。
- **把增强看作分布干预，而不是数据扩充**。问一下自己：这个增强把训练分布往哪一个方向推进？那个方向是目标分布吗？
- **小样本优先尝试简单、保持标签完整的增强**
- **用平台/真实测试信号验证增强，而不只靠本地验证**
- **负结果要记录。**
