# E06：2×2 因子实验——"门"的死刑

> H_D 为什么赢？最直觉的答案是功能门控：recon 阶段把 edit 工具藏起来，agent 只能先侦察。2×2 因子实验给了一个干净利落的答案：加门不改变任何东西，加横幅改变一切。**H_P（只有横幅）逐实例复现了 H_D，H_G（只有门）躺地板。**

---

## 1. 研究问题与假设

E05 留下机制悬念：分阶段 harness（H_D）为什么赢？

- **假设 H11**：affordance gating（功能门控）是 H_D 背后的机制——移除 edit 工具让 agent 在侦察完成前无法行动。

## 2. 设计：教科书式的 2×2

固定模型（dots3）、任务集（宽集 20 实例）、预算 T∈{2,4,6,8}（主操作点 T=6），`SWE_LAB_PROMPTS` / `SWE_LAB_GATE` 是仅有的两个开关：

| | 门 OFF | 门 ON |
|---|---|---|
| **横幅 ON** | **H_P**（每轮阶段横幅，edit 全程可用） | **H_D**（横幅 + 门） |
| **横幅 OFF** | H_A（自由 agent） | **H_G**（门控 edit，无横幅） |

再加一臂 **H_ADAPT**：确定性自适应调度器（recon → execute → verify，从观察到的调用驱动状态机）——测"更聪明的门"能不能在固定门失败的地方成功。

## 3. 一个诚实的失误：跑错了操作点

Phase 6A 最初把 2×2 跑在宽集 × T=4 上，结果发现那个操作点解 rates 只有 0–7.5%——**地板区**，因子实验在 n=40 下欠功效（提交 `3117af867`）。

档案的处理方式不是删除这组数据，而是**记录并绕行**：地板区的数据保留在案，决定性证据改由 T=6 分解 + pilot 复现承载。retrospective 对此的批评很直接："欠功效的因子实验不是失败的实验，是**没有被执行过的实验**"——操作点应该先于因子设计被选定。这条教训后来进了 15 篇的清单（"操作点先行"）。

## 4. 结果：门死了

**T=6 分解（决定性一役，提交 `6aea58419`）**：

| 臂 | 解 rates |
|---|---|
| H_P（只有横幅） | **5/20 = 25%** |
| H_D（横幅 + 门） | **25%** |
| H_G（只有门） | **1/20（地板）** |

**Pilot 确认（提交 `ce618eed3`）**：H_P 逐实例复现 H_D——**7/16 = 44%，同样的实例**，edit 工具全程在场。门控对结果的贡献精确为零。

**H_ADAPT 的死刑**：从未赢过固定调度（自带两轮侦察税，首次编辑被推迟），它的 verify 规则**从未触发过**（提交 `8f7a62b84`）。v1 自适应规则校准失败——"更聪明的门"这个方向至少在当前形式下是空话。

**first_edit_turn 分解**（提交 `b2207c3d4`）：H_G **没有**把首次编辑推得更早，H_P **有**。行为差异跟着横幅走，不跟着门走。

## 5. 一个必须在此声明的指标修复

Phase 6 中段发现 `WRITE_RE` 把 `2>/dev/null` 和 `2>&1` 误判为树写操作（提交 `4b6854707`）——修复前 H_A 的真实编辑数被记为 0.5/ep，实际是 0/20。

档案为此立了一条永久规则：**本档案所有条件写率必须在该修复之后读取**。后来（15 篇）它进一步升级为"指标修复需要向后传播"的教训——一个旧 writeup 引用修复前的条件写率，读者会读到 54% vs 25% 的差距，而修正后是 100% vs 100%。**测量 bug 的可怕之处不在它存在，在于它污染过的每一个历史读数都还留在纸上。**

## 6. 解释

效应不是工具可得性，是**每轮对当前阶段的重申**。这个结论一举完成了三件事：

- 杀死 H04 的残余读法（"工具集是杠杆"）在 harness 情形下的最后阵地；
- 把整个研究程序转向 E07：如果横幅是机制，那它**哪个属性**承重——重复、内容还是角色？
- 顺手否决了"自适应调度"这个当时最有吸引力的工程方向——停止研究它，才让 Phase 7 有时间存在。

## 7. 一句话总结

> 因子实验的威力在于它不问"X 有没有用"，而问"X 和 Y 同时在场时，谁在干活"。答案是：门在假装干活，横幅在干活。

下一篇把横幅拆开：七臂分解出三个可分离的杠杆——重复、内容、角色，代价是全部单种子。
