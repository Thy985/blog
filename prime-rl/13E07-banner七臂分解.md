# E07：banner 七臂分解——三个可分离的杠杆

> 横幅承载效应，但横幅是复合物：它重复、它有内容、它站在 user 角色上。七臂分解把三者拆开——重复是必要条件，内容是独立杠杆，角色不可互换。三个单因素臂各损失约 10 分。代价：全部单种子 n=20，E08 将对这份名单逐一清算。

---

## 1. 研究问题与假设

E06 证明横幅是机制（12 篇）。本篇问它内部的结构：

- **H12**：逐轮重复阶段上下文是必要的——**成立**。
- **H13**：消息角色承重——**成立但被收窄**。
- **H14**：内容与节奏是独立、不可替代的杠杆——**成立**。
- **H15**：阶段边界时机是第四个维度——**E08 拒绝**（伏笔）。

## 2. 设计

固定 dots3、宽集 20 实例、T=6、edit 全程可用，只动每轮注入（`SWE_LAB_BANNER`）。七个臂，每臂 20 episodes：

| 臂 | 注入 |
|---|---|
| H_A | 无 |
| H_ONCE | 只在第一轮注入一次 |
| H_NEUTRAL | 中性文本，每轮 |
| H_ACTION | 动作导向文本，每轮 |
| H_PHASE | 每轮只报阶段名 |
| H_P | 完整阶段上下文，每轮 |
| H_SYS | 与 H_P 相同文本，但放 **system** 角色 |

H_SYS 是专门为 H13 造的：同文本、同节奏、只换角色（`SWE_LAB_BANNER_ROLE=user` vs `system`）。

## 3. 结果

| 臂 | 注入 | 解 rates |
|---|---|---|
| H_A | 无 | **0%** |
| H_ONCE | 一次 | **5%** |
| H_NEUTRAL | 中性，每轮 | **5%** |
| H_ACTION | 动作导向，每轮 | **15%** |
| H_PHASE | 阶段名，每轮 | ~15%（与 H_ACTION 打平）* |
| H_P | 完整上下文，每轮 | **25%** |
| H_SYS | H_P 文本，system 角色 | **15%** |

\* 两个 H_PHASE rollout 是 600s 超时，15% 是下限，稀释结论偏保守（提交 `7e8346b05`）。

**三个互相独立的杠杆**：

1. **重复**（H_ONCE → H_P 系）：一次注入 5%，逐轮注入 15–25%。**必要条件**——没有重复，其他一切都归零。
2. **内容**（H_NEUTRAL → H_ACTION，同为每轮）：中性状态文本惰性（5%），动作导向内容到 15%。内容是次要但真实的杠杆。
3. **角色**（H_P → H_SYS，同文本同节奏）：user 25% vs system 15%。角色不可互换。

三个单因素臂各损失约 10 分，且互不可替代。H_ACTION 与 H_PHASE 的打平是最干净的内容/节奏分离。

## 4. 一次测量修正

五臂结果公布后，注入计数的测量被修正（提交 `7ca05d71d`）：H_ACTION / H_PHASE 实际是**每轮**注入而非阶段边界注入。修正后杠杆归因更干净：内容 5%→15%（中性→动作），完整阶段上下文进一步到 25%。这个插曲也是 15 篇"每条事实一个入口"的又一案例——注入次数这种基础事实也必须有单一权威来源。

## 5. 边界声明

H_SYS 的角色对比有一个容易被读过头的地方（提交 `d0985e941`）：它只证明 **system 注入 ≠ user 注入**，**不证明"打断"是因果机制**——要测打断的因果性得控制"打断但无害"的对照，实验没做。术语由此定稿为"user-turn runtime intervention"（用户轮运行时干预）/ "per-decision control-plane injection"（逐决策控制面注入），并写进主张矩阵的"不可主张"清单。

## 6. 三层模型的完成

E07 补上了机制的最后一层，三层模型成形：

1. **Phase 5（E04–E05）**：harness 改变行为；
2. **Phase 6（E06）**：改变它的不是工具门；
3. **Phase 7（E07）**：是运行时上下文注入，且角色、节奏、内容各有贡献。

中介物的轮廓也已可见：`n_calls` 持平而 inspect / edit 的分布移动——横幅改变的是**动作分配**，不是认知努力总量。但严格的中介链验证要等 E08 的 n=60。

## 7. 遗留的软肋

全部七个臂**单种子 n=20**。档案自己写得很清楚："这正是 E08 必须修复的。"H_P 的 25%、H_SYS 的 15%、三个杠杆的精确幅度——每一个都带着种子噪声在传播。E07 的价值是**结构**（三个杠杆的分离），它的数字要在 E08 里重新估价。

## 8. 一句话总结

> 分解实验的产出是一份杠杆清单和一份噪声清单——在同一次运行里。哪些是结构、哪些是种子，当时分不出来，所以结构要留到复制之后才算数。

下一篇是整个档案最重要的实验，而且它是一个"负结果"：复制到 n=60，headline 腰斩，一个维度死亡，只有两个配对检验幸存。
